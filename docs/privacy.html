Privacy policy

ToolboxTop10 is a static website. There are no accounts, no sign-up forms, no comments and no newsletter, so we never ask for your name, email or payment details.

Analytics

We use Cloudflare Web Analytics to count page views. It doesn't set cookies, doesn't use fingerprinting and doesn't track you across other sites. We see totals such as page views, referring sites and country, not individual visitors.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub records technical details of each request, including IP addresses, for security and operations. GitHub's privacy statement covers that data; we don't get access to it.

Retailer links

When you click a link to Amazon, you leave this site. The retailer may set its own cookies, including affiliate cookies that tell it the visit came from ToolboxTop10 so it can pay us a commission. That data is handled under the retailer's privacy policy. We see sales totals, never who bought what. See our affiliate disclosure.

Product images

Product images load from Amazon's image servers, which receive the request like any other web request.

Email

If you email us, we use your address and message only to reply. We don't add you to any list or share it with anyone.

Selling or sharing data

We don't sell or share personal information, and we don't have any to sell.

Children

The site isn't aimed at children under 13 and doesn't knowingly collect anything from them.

Changes and contact

If this policy changes, the date below changes with it. Questions go to admin@toolboxtop10.com.
