How we rank

The list is ordered by that score. Best Overall is our pick for the best all-around, ready-to-use tool; Best Budget the best value at or under $70; and Money No Object the one to buy if price is no object.

The features score is built from cast iron (35%), slow speed (35%), light (30%), capped at 100. The review-count score is on a log scale, so each tenfold jump in reviews adds the same amount, and 3,000 or more reviews gets full marks. Open Why this score on any tool to see its numbers.

Buyer's guide

6-inch or 8-inch?

6-inch grinders cover blades, knives and drill bits in a home garage. 8-inch wheels last longer, run at a higher surface speed and give more room between the wheels for bigger parts.

What is a low-speed grinder for?

Low-speed grinders run about 1,750 rpm instead of 3,450. The slower wheel heats the edge less, so chisels, plane irons and turning tools don't lose their temper. For metal work, standard speed is faster.

Which grit wheels do I need?

A coarse wheel (36 grit) for shaping and removing metal, and a finer wheel (60 to 120 grit) for sharpening. White aluminum oxide wheels run cooler than the gray ones and suit tool steel.

Do I need to bolt a bench grinder down?

Yes. Bolt it to a bench or stand so it can't walk or tip, and set the tool rests within 1/8 inch of the wheel so work can't get pulled in.

Can I put a wire wheel on a bench grinder?

Yes, on most models, as long as the wheel's arbor size and maximum rpm match the grinder. A wire wheel strips rust and paint and cleans up welds.
