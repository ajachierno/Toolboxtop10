DEWALT questions

Is DEWALT 20V MAX the same as 18V?

Yes, in practice. "20V MAX" is the battery's peak voltage with no load; under load it runs at a nominal 18V, the same as other brands' 18V tools. The number is marketing, not extra power.

Do DEWALT FLEXVOLT batteries work in 20V MAX tools?

Yes. FLEXVOLT batteries switch voltage automatically and run 20V MAX tools. It doesn't work the other way: a 20V MAX battery won't power a 60V FLEXVOLT tool.

What does XR mean on DEWALT tools?

XR is DEWALT's premium 20V MAX line. XR tools are usually brushless, with more power and runtime than the standard 20V MAX versions. They cost more, and our scores show whether that premium pays off in each category.

Should I buy a bare tool or a kit?

If you already own DEWALT 20V MAX batteries and a charger, buy the bare tool ("tool only"). It's the same tool for much less money. If this is your first DEWALT cordless tool, buy a kit so you get a battery and charger in the box.

Why isn't DEWALT listed in every category?

We only show DEWALT tools that made our ranked top 10. Where no DEWALT made the cut, we link to that list so you can see the best from any brand.
